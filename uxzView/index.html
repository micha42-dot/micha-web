Funktionen Features

Ordner-Browsing & Cache Folder Browsing & Cache 0,24 ms
Blitzschnelles Navigieren in Ordnern mit Tastatursteuerung und speichereffizientem RAM-Lookahead-Caching für nahtloses Bildwechseln. Fast folder browsing with full keyboard navigation and memory-efficient RAM lookahead caching for seamless image transitions.
Vollbild, Zoom & Diashow Fullscreen, Zoom & Slideshow F11 / Space
Ablenkungsfreie Vollbildansicht mit Maus-Navigation, automatischen Diashows und bereichsspezifischem Zoom in ausgewählte Bildausschnitte. Distraction-free fullscreen viewing with mouse navigation, automatic slideshows, and region-specific zoom into selected image areas.
Info-Ecken & Metadaten-HUD Metadata HUD & Corner Info I Taste I key
Einstellbare Info-Einblendungen in beliebigen Bildecken (Auflösung, DPI, Dateigröße, Kamera, Objektiv, EXIF/IPTC/XMP) sowie RGB-Echtzeit-Histogramm. Customizable corner info overlays (resolution, DPI, file size, EXIF/IPTC/XMP metadata) plus real-time RGB histogram.
Zentrierte Nachbarleiste Centered Culling Strip 1–5 Frames
Optionale, zentrierte Vorschauleiste zum Direktvergleich von 1–5 vorherigen und nachfolgenden Bildern für schnelles Culling. Optional centered thumbnail strip displaying 1–5 preceding and succeeding images for fast culling and comparisons.
Befehlssuche & Palette Command Palette & Search Shift+T
Direkte Suche und Schnellausführung aller Bearbeitungsbefehle und Werkzeuge über die Toolbar oder per Tastatur. Instant search and execution of all editing commands and tools directly from the toolbar or quick keyboard launcher.
Bearbeitung & Korrekturen Editing & Adjustments Crop / Color
Skalieren, Zuschneiden mit Seitenverhältnis-Presets oder frei, Drehen, Spiegeln, Farbanpassungen und automatische Bildkorrektur. Resize, crop with preset or custom aspect ratios, rotate, flip, color adjustments, and automatic image enhancement.
Visuelle Stapelverarbeitung Visual Batch Processing Profiles & Watermarks
Stapelverarbeitung ganzer Bildordner mit wiederverwendbaren Profilen, Wasserzeichen und echten Export-Echtzeit-Vorschauen. Batch processing with reusable profiles, custom watermarks, and real-time export previews before processing.
Verwaltung & Duplikate Ratings & Duplicate Search 1–5 Stars / Labels
Sterne-Bewertungen, Farblabels, gezielte Metadaten-Suche und automatische Erkennung doppelter Aufnahmen. Star ratings, color labels, targeted metadata search, and automated duplicate image detection.
Interner Papierkorb & Undo Internal Trash & Undo Ctrl+Z
Internes Papierkorb-Journal, lückenlose Historie aller Dateioperationen und atomares Rückgängigmachen (Undo per Ctrl+Z). Internal trash integration, full file-operation history, and atomic undo via Ctrl+Z.
Screenshots & Shortcuts Screenshots & Keybindings Custom Keys
Konfigurierbares Screenshot-Werkzeug und frei anpassbare Tastaturkürzel für sämtliche Aktionen. Configurable screenshot capture utility and customizable keyboard shortcuts for all operations.
Offline OCR & QR-Reader Offline OCR & QR/Barcode 100% Offline
Lokales Auslesen von QR-/Barcodes und optische Texterkennung (OCR) aus dem Gesamtbild oder einer Rechtsklick-Auswahl, inkl. deinstallierbarer Sprachpakete. Local QR/barcode scanning and optical text recognition (OCR) from whole image or right-click selection, with modular language packs.
Format- & Funktions-Plugins Extensions & Plugins Modular
Getrennte Erweiterungen für zusätzliche Bildformate und Funktionen mit frei konfigurierbaren Speicherpfaden. Separate image-format and functional extensions with customizable storage directories.

Optionaler Portable-Modus: Alle Einstellungen, Profile, Bewertungen, Erweiterungen und Historie werden direkt neben der Anwendung gespeichert. Optional portable operation storing settings, profiles, ratings, plugins, and file history alongside the executable.
Mehrsprachiges UI Multi-Language UI DE / EN / KO / JA / FR
Interface verfügbar in Deutsch, Englisch, Koreanisch, Japanisch und Französisch. User interface supported in German, English, Korean, Japanese, and French.

git clone https://github.com/micha42-dot/uxzView.git
cd uxzView
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j $(nproc)
./build/üxzView
1. Abhängigkeiten via Homebrew installieren: 1. Install dependencies via Homebrew: 
brew install cmake qt libraw
2. Kompilieren (mit Homebrew Qt-Pfad) & starten: 2. Compile (with Homebrew Qt prefix) & run: Homebrew installiert Qt 6 isoliert (keg-only). CMAKE_PREFIX_PATH übergibt den Pfad automatisch an CMake. Homebrew installs Qt 6 as keg-only. CMAKE_PREFIX_PATH passes the path automatically to CMake. 
git clone https://github.com/micha42-dot/uxzView.git
cd uxzView
cmake -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="$(brew --prefix qt)"
cmake --build build --config Release -j $(sysctl -n hw.ncpu)
./build/üxzView

Das KI-Experiment & 1E9 AI Experiment & 1E9

Entwickelt wurde mit den Assistenten Codex und Cline auf Basis der Sprachmodelle GPT-6 Astra, GPT-6.1 Sol, Kimi K3 und GLM 5.3. Development relied on the coding assistants Codex and Cline, powered by the AI models GPT-6 Astra, GPT-6.1 Sol, Kimi K3, and GLM 5.3. The project also serves as a journalistic experiment: in a two-part article series for the tech magazine 1E9 , Michael documented the creation, hurdles, and takeaways of building native desktop software using AI.
